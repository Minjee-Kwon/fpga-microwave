# 기능 동작 확인용 테스트벤치

## 목적

복잡한 자동 검증 대신 실제 `microwave_top`의 기본 동작 순서를 파형으로 확인합니다. `sim/tb_microwave.v` 한 개를 사용합니다.

## 실행

Vivado Tcl Console에서 저장소 폴더로 이동한 뒤 `source sim/run_sim.tcl`을 실행합니다. Simulation Top은 `tb_microwave`입니다. 파형을 추가하려면 `source sim/waves.tcl`을 실행합니다.

## 확인 순서

| 순서 | 입력 | 파형에서 볼 내용 |
|---|---|---|
| 1 | 로터리 CW 3회, CCW 1회 | remaining=2 |
| 2 | 센터 버튼 | running=1, 5ms 뒤 EN=1, 방향 01 |
| 3 | 운전 중 로터리 | remaining 유지 |
| 4 | 취소, CW 1회, 재시작 | 정지 시 EN=0, remaining=3으로 변경, 재시작 |
| 5 | 문 열기 | door_open=1, running=0, EN=0, 서보 위치 변경 |
| 6 | 문 닫기 | door_open=0, running=0, 자동 재시작 없음 |
| 7 | 모드1, 모드2 | LED1·LED2, 방향 10·01·10 변화 |
| 8 | 시간 종료 | remaining=0, done 펄스, EN=0, finish와 종료음 |
| 9 | 새 시간 설정 후 센터 | remaining=1, running=1, EN=1 |

## 짧게 실행하기 위한 처리

- 일반 버튼은 디바운스가 끝난 `clean_pulse`에 테스트용 펄스를 넣습니다. 이 테스트에서는 10ms 버튼 디바운서 자체를 확인하지 않습니다.
- 타이머의 1초와 모터 교대의 3초는 내부 카운터를 끝값으로 이동해 대기 시간을 줄였습니다. 원본 RTL은 수정하지 않습니다.
- 서보는 실제 20ms 프레임을 기다립니다. 파형에서 닫힘 1ms, 열림 1.5ms 폭을 확인할 수 있습니다.
- 로그는 관찰할 값과 실제 신호값을 출력합니다. 자동 PASS 판정이나 전수 검증은 포함하지 않습니다.
- 완료 점멸 3회 전체, 모든 음계의 정확도, 모든 FND 숫자 패턴은 이 기본 동작 테스트의 범위 밖입니다.
